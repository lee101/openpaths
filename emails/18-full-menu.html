Beyond Text: Vision, Embeddings & Image Gen

OpenPaths isn't just a text router. Through the same API and the same key, you can access multimodal vision models, fast embedding models, and image generation pipelines. Here's what's available.

👁️ Vision Models

All the major multimodal models support image input through the standard OpenAI vision format. Send a URL or base64-encoded image and get analysis back.

Kimi K3

Vision over a 1M context, open weights
