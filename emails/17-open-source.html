Why Open Source Matters Here

OpenPaths is fully open source. The routing logic, the provider integrations, the embedding models — all of it is available for you to audit, fork, or self-host. This isn't just a philosophical position; it has practical benefits for every user.

The architecture in brief

OpenPaths uses a static embedding model that runs locally in microseconds — no GPU needed — to classify incoming requests. This embedding is compared against a set of routing rules that map task types to cost-optimal model tiers.

The whole routing decision happens in under 5 milliseconds with no additional API call. This is what keeps auto-routing fast and cheap — it doesn't require a separate LLM call to decide which LLM to call.

The server is written in Go — fast, single binary, minimal dependencies. The frontend is React. Everything is MIT licensed.
