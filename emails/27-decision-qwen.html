Typed decisions with probabilities, plus Qwen 3.8 Max, Omni and Wan 3.0 video

A lot landed since the last note. The new one is decision-model-preview: a model that does not write prose. You hand it a state and a few typed questions, and it answers yes/no, multiple choice and rubric scores in one pass, with probabilities and confidence on every answer. It is wire-compatible with the TypeSafe /v1/systemone API, so existing TypeSafe SDKs work with the base URL set to OpenPaths.

One call, three decisions

We ran a support ticket through it: "My card was charged twice for the same order and I want my money back today." Three questions, 96 input tokens, 598 ms:

Urgent? · yes, 0.91

A noul question returns the probability that the answer is true.

Which team? · billing, confidence 0.99

A choice question returns the winner plus the full distribution: billing 0.99, tech 0.01, sales 0.00.

How angry? · 3.25 on a 0-4 scale

A score question returns the weighted score and the probability of each level: angry 0.62, furious 0.32.

It bills at $0.042 per million input tokens and output is free, with a 64K input window. That is cheap enough to put in front of every ticket, moderation check, agent-routing step or result validation, and the probabilities let you route low-confidence cases to a human instead of guessing.

curl https://openpaths.io/v1/systemone \
  -H "Authorization: Bearer $OPENPATHS_API_KEY" \
  -d '{"model":"decision-model-preview","state":{"ticket":"Charged twice, refund me today"},
  "questions":{"team":{"type":"choice","instructions":"Which team?",
  "criteria":{"billing":"payments, refunds","tech":"bugs, outages","sales":"pricing"}}}}'
