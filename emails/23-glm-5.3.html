GLM-5.3 is live

Z.AI shipped GLM-5.3, and it is routable on OpenPaths today. It has a 1M token context window, always-on reasoning, and it costs exactly what GLM-5.2 did.

glm-5.3 · Z.AI · 1M context

$1.40 in / $4.40 out per 1M tokens. Tool use, streaming, and 131K max output. Falls back automatically to a second provider if Z.AI has a bad minute.

Same price, so we routed everything up

GLM-5.2 and GLM-5.1 cost the same as 5.3, so those model ids now serve GLM-5.3. You get the newer model at the price you were already paying, with no code change. If you need an exact version, zai/glm-5.1 and fireworks/glm-5.2 stay pinned.

glm-latest

New alias that always points at the newest GLM we route. Set it once and stop editing model ids.

Reasoning that just works

GLM-5.3 always thinks and only accepts low, high, and max. Send whatever reasoning_effort you already use, including none, and OpenPaths maps it to the nearest level the model supports instead of erroring. The same mapping now covers Gemini, Mistral, Grok, Qwen, and GPT-5.6, so one request shape works across every model we route.

curl https://openpaths.io/v1/chat/completions \
  -H "Authorization: Bearer $OPENPATHS_API_KEY" \
  -d '{"model":"glm-latest","messages":[{"role":"user","content":"say only hi"}]}'
