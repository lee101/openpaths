Your First API Call

OpenPaths is OpenAI-compatible. If you've used the OpenAI SDK, you already know how to use OpenPaths. Just change the base URL and API key.

Python

from openai import OpenAI client = OpenAI( base_url="https://api.openpaths.io/v1", api_key="op-your-key" ) response = client.chat.completions.create( model="auto-think", messages=[{"role": "user", "content": "Hello!"}] )

curl

curl https://api.openpaths.io/v1/chat/completions \ -H "Authorization: Bearer op-your-key" \ -H "Content-Type: application/json" \ -d '{"model":"gpt-5.4-mini","messages":[{"role":"user","content":"Hi"}]}'
