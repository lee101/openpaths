The free model is back

openpaths/free is back, powered by MissingNo through Nous Research. It is an anonymous, free reasoning model with a 262K context window and tool calling. Its identity is undisclosed. Use it with your existing OpenPaths API key.

{{.Model.Card}}

We gave MissingNo the house creative-coding test: a pelican riding a bicycle as an animated SVG. One attempt took 8.462 seconds and 3,327 completion tokens (1,479 reasoning tokens); the provider reported $0 cost. It produced a recognisable bird, spinning wheels and an animated crank. The throat pouch and static legs need polish: this is a promising creative-code sample, not a coding benchmark score.
