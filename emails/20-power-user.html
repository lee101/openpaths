Advanced Patterns

Multi-key isolation. Create separate API keys for production, staging, and dev. Track usage per environment in your dashboard.

Model pinning. Use auto tiers for development, then pin to a specific model in production for predictable behavior and costs.

Streaming everywhere. Add stream=True to reduce time-to-first-token. Works across all providers.

Reasoning effort. Use reasoning_effort="low" for tasks that don't need deep thinking - saves tokens and latency.

Batch cheap tasks. Route classification, tagging, and extraction to auto-easy-task at $0.02/M. Reserve flagship models for tasks that actually need them.
