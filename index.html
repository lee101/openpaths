One OpenAI-compatible API for every model

OpenPaths gives you a single key and base URL (https://openpaths.io/v1) for language, image, video, speech, music, embedding and 3D models. It speaks the OpenAI and Anthropic schemas, routes with openpaths/auto, retries on another provider when one fails, and keeps markup near zero. Bring your own provider keys and those requests record $0.

Common questions

Is it compatible with the OpenAI and Anthropic SDKs?

Yes. Use /v1/chat/completions or /v1/messages and only change the base URL.

How is it priced?

Pay as you go at provider prices with near-zero markup; BYOK requests record $0.

How do agents discover the API?

Through /openapi.json, /.well-known/api-catalog, /llms.txt and the /mcp endpoint.
